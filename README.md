## Sobre o projeto

O GISA.DEV — Link Hub foi desenvolvido para funcionar como uma página personalizada de links, permitindo centralizar diferentes plataformas e projetos através de uma única URL.

A ideia é utilizar essa página como https://www.instagram.com/gisa.dev?utm_source=qr&igsh=NXV6MHdnNDlxNzNy, facilitando o acesso ao meu GitHub, LinkedIn, portfólio, WhatsApp e comunidades.

Em vez de disponibilizar vários endereços separadamente, o visitante encontra tudo organizado em blocos interativos.
